## 2. Granular 30-Day Execution Sprints

### Month 1: Foundation, Indexing Stabilization & Core Hygiene (Days 1–30)
* **Week 1:**
  * Complete Phase 01 Audits & Framework documents in `seo-docs/`.
  * Present Owner Verification Queue (OVQ) to stakeholder for GBP and business details.
  * Implement formal npm validation scripts (`npm run validate-business`, `npm run typecheck`, etc.).
* **Week 2:**
  * Actively inspect clean canonical URLs in Google Search Console to accelerate recrawl and indexing.
  * Verify edge 308 redirect handling across all legacy `.html` requests.
  * Audit Google Business Profile alignment and ensure NAP consistency with Jakkur base.
* **Week 3:**
  * Harden internal linking between existing blog guides and the 6 primary service pillars.
  * Connect `/bihari-pandit-bangalore` and `/maithil-pandit-bangalore` into the main ritual clusters to clear "Crawled - currently not indexed" status.
* **Week 4:**
  * Configure and test GA4 custom conversion events (`whatsapp_click`, `phone_call_click`, `booking_submit`).
  * Run 30-day technical SEO re-crawl and Core Web Vitals benchmark.
